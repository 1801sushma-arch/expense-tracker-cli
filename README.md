# expense-tracker-cli (Python CLI)

## 📌 Description
A command-line based expense tracker that helps users record and manage daily expenses.

## 🚀 Features
- Add expense (date, category, description, amount)
- View all expenses
- Calculate total spending
- Save data to JSON file

## 🧠 Concepts Used
- Lists & Dictionaries
- Loops and Conditions
- File Handling (JSON)
- Exception Handling

## ▶️ How to Run
1. Install Python
2. Run:
   python expense-tracker.py

## 💡 What I Learned
- How to structure a menu-driven program
- Managing real-world data using dictionaries
- JSON file handling for data persistence
- Handling user input and edge cases
